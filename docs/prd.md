# 수원시보건소 모바일 웹 개편 PRD

## 1. 문서 개요
- 프로젝트명: 수원시보건소 모바일 웹 개편
- 참여 기간: 2026.09.30 ~ 2026.10.15 (10일)
- 테마: (직접 작성)
- 준수 기준: KRDS 2025.08, KWCAG 2.2
- 벤치마킹: 강서보건소, 송파보건소, e보건소

## 2. 배경과 문제 정의
수원시보건소는 장안·권선·팔달·영통 4개 구가 함께 쓰는 통합 포털입니다. 그런데 관할 보건소 방문 안내가 없고, 거주자 전용 서비스와 누구나 이용하는 서비스가 같은 형태로 섞여 있습니다.

| 번호 | 문제 | 설명 |
|---|---|---|
| 1 | 관할 입구 없음 | 주민등록등본 기준 관할 안내와 지역 선택 버튼이 첫 화면에 없습니다. |
| 2 | 서비스 혼재 | 관할 서비스, 통합 서비스, 긴급·비긴급 서비스가 구분 없이 나열되어 있습니다. |
| 3 | 긴급 정보 접근성 | 휴일·야간 이용 정보가 눈에 띄지 않는 곳에 있습니다. |

우선순위 과업: 타이틀 없는 아이콘과 배너 박스가 나열되어 있어, 정리 후 재배치하고 어려운 용어에 부가 설명을 붙입니다.

## 3. 과업 목표
1. 관할구역 착오 방문(헛걸음)을 방지합니다.
2. 핵심 정보(관할, 통합, 위급)의 탐색 시간을 단축합니다.

## 4. 타겟 페르소나
| 항목 | 내용 |
|---|---|
| 이름 | 이단비 (34세, 여성, 육아휴직 중인 회사원) |
| 상황 | 최근 팔달구로 이사해 전입신고를 마친 초보 엄마이며, 8개월 된 아기를 키웁니다. |
| 사용 환경 | 아기가 낮잠 자는 틈에 모바일로 한 손 조작을 합니다. 직접 전화·방문할 여유가 부족해 모바일 웹 의존도가 높습니다. |
| 목표 | 영유아·모성 지원(관할 사업)을 신청하고, 예방접종도 함께 확인합니다. |
| 불안 요소 | 관할 보건소를 몰라 다른 구에 갔다가 거절당할까 걱정합니다. |

해결 포인트
- 거주지 사전 확인으로 헛걸음을 방지합니다.
- 지역 관할 서비스(모성지원, 영유아지원 등)를 인지하게 합니다.
- 통합민원서비스를 거주 구와 관계없이 쉽게 이용하게 합니다.

## 5. 핵심 과업: 내 지역 버튼과 카드 재배치
| 영역 | 내용 |
|---|---|
| ① 보건 주요 서비스 | 주민등록등본 기준 관할 서비스입니다. 내 지역 버튼을 도입하고 의료비지원을 둡니다. |
| ② 통합민원서비스 | 거주지와 관계없이 이용하는 서비스입니다. 제증명발급, 예방접종, 진료및검사, 금연서비스 4개입니다. |
| ③ 긴급원클릭서비스 | 기존 '원클릭서비스'를 위급 목적으로 재정립합니다. |
