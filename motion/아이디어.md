# 아이디어.md — 홍보 모션 영상 장면별 화면·분리 요소

> 이 파일의 역할: 홍보 모션 영상의 장면마다 쓸 화면과 분리 요소를 정리한 표입니다.

## 1. 장면별 사용할 화면

| 장면번호 | 사용할 화면 | 이유 |
|---|---|---|
| 1 질문 문구 | 없음 | 글자만 나오는 장면 |
| 2 메인 스크롤 | 모바일 1 메인 (`screen-01-main-full.png`) | 주의 상자·구 버튼·통합민원이 한 화면에 있어 스크롤로 보여 주기 좋음 |
| 3 구 선택 → 팔달보건소 | 모바일 1 메인 → 모바일 2 팔달보건소 (`screen-02-district.png`) | 「구를 누르면 끝」 흐름. 누른 모양은 `part-region-paldal-pressed.png` |
| 4 예방접종 | 모바일 4 예방접종 (`screen-04-vaccination.png`) | 영유아를 키우는 핵심 사용자에게 가장 필요한 정보, PRD 성공 지표 3번 |
| 5 위치·교통 | 모바일 7 위치·교통 (`screen-07-location.png`) | 지도가 있어 눈에 잘 띔, PRD 성공 지표 4번 |
| 6 긴급원클릭서비스 | 모바일 1 메인의 긴급바 (`part-emergency-bar.png`) | 밤·휴일 긴급 상황을 버튼 3개로 바로 보여 줌 |
| 7 엔딩 | 없음 | 로고와 문구만 나오는 장면 |
