# 수원시 보건소 앱 개선 프로젝트

> 수원시 보건소 앱에 내 지역 버튼을 도입해 헛걸음을 줄인 개선안
> 보건 주요 서비스 카드를 재배치해, 필요한 서비스를 주소지 보건소에서만 신청할 수 있는지 가까운 보건소에서도 신청할 수 있는지 한눈에 알 수 있도록 함

## 2. 프로젝트 정보

- **제작 기간**: 2026.11.06 ~ 2026.11.09 (4일)
- **담당 역할**: 개인 프로젝트 (기여도 100%)
- **담당 범위**: Figma 개선 디자인 → 바이브코딩 구현 → GitHub Pages 배포

## 3. 사용 기술

- **React, Vite**: 화면을 컴포넌트로 나눠 수정하기 쉽게 구현
- **GitHub Pages**: 무료 배포
- **Figma**: 개선 디자인
- **Claude**: 바이브코딩 (화면 구현)

## 4. 주요 기능

- 기능 1: 서비스 카드를 세 영역(보건 주요 서비스 / 통합민원서비스 / 긴급원클릭서비스)으로 재배치해, 사용자가 원하는 서비스가 어떤 종류인지 쉽게 알고 알맞은 경로를 고를 수 있음
- 기능 2: 내 지역 버튼 도입 — 첫 화면의 안내문과 내 지역 버튼을 통해 사용자가 관할 보건사업을 헛걸음 없이 찾을 수 있음
- 기능 3: 모바일·데스크톱 반응형 레이아웃

## 5. 트러블슈팅

### 이슈 1: 배포 후 404 에러 화면이 나옴

- **문제**: 배포 후 주소 링크 공유 시 에러 화면이 나옴
- **원인**: 저장소가 Private으로 되어 있었음
- **해결**: Public으로 변경 후 재배포

## 6. AI 활용 방식

- **맡긴 일**: Figma 화면을 React 컴포넌트로 구현
- **핵심 프롬프트**: "이 프레임을 모바일 너비(360px~), 데스크톱(1440px~) 기준으로 구현해 줘"

## 7. 회고

- **배운 점**: 배포 전 저장소가 Public인지 꼭 확인하고 배포할 것
- **아쉬운 점**: 모바일 기준으로 구현하다 보니 태블릿 화면 기준은 구현하지 못함
