# 수원시 보건소 앱 개선 프로젝트

> 수원시 보건소 앱에 내 지역 버튼을 도입해 헛걸음을 줄인 개선안<br>
> 보건 주요 서비스 카드를 재배치해, 필요한 서비스를 주소지 보건소에서만 신청할 수 있는지, 가까운 보건소에서도 신청할 수 있는지 한눈에 알 수 있도록 함<br>
> 관할·통합·긴급 정보를 나눠 배치해 필요한 정보를 찾는 시간을 줄임

## 2. 프로젝트 정보

- **제작 기간**: 2026.11.06 ~ 2026.11.09 (4일)
- **담당 역할**: 개인 프로젝트 (기여도 100%)
- **담당 범위**: Figma 개선 디자인 → 바이브코딩 구현 → GitHub Pages 배포

## 3. 사용 기술

- **React, Vite**: 화면을 컴포넌트로 나눠 수정하기 쉽게 구현
- **GitHub Pages**: 무료 배포
- **Figma**: 개선 디자인
- **Claude**: 바이브코딩 (화면 구현)

## 4. 주요 기능

- **기능 1. 서비스 카드 재배치와 내 지역 버튼**: 서비스 카드를 보건 주요 서비스, 통합민원서비스, 긴급원클릭서비스의 세 영역으로 나눠, 원하는 서비스가 어떤 종류인지 알고 알맞은 경로를 고를 수 있음. 첫 화면의 안내문과 내 지역 버튼으로 관할 보건사업을 헛걸음 없이 찾을 수 있음
- **기능 2. 의료비지원·위치·공지 안내**: 의료비지원 메뉴 11개를 누르면 해당 지원사업의 자격과 지원 내용을 바로 확인할 수 있음. 구별 보건소의 주소, 지도, 운영·점심시간, 대중교통·주차 정보를 한 화면에서 보고, 공통·팔달·권선·장안·영통 버튼으로 지역별 최근 공지도 골라 볼 수 있음
- **기능 3. 긴급원클릭서비스 하단 고정과 반응형 레이아웃**: 휴일지킴이, 자동심장충격기 찾기, 달빛어린이병원을 화면 하단에 고정해 휴일·야간에도 바로 찾을 수 있음. 모바일과 데스크톱 모두에서 같은 기능을 편하게 쓸 수 있도록 반응형으로 구현함

## 5. 트러블슈팅

### 이슈 1: 배포 후 404 에러 화면이 나옴

- **문제**: 배포한 주소를 공유했더니 접속 시 404 에러 화면이 나옴
- **원인**: GitHub 저장소가 Private으로 설정되어 있어 GitHub Pages가 공개되지 않았음
- **해결**: 저장소를 Public으로 바꾸고 다시 배포한 뒤, 정상 접속되는 것을 확인함

### 이슈 2: 아코디언 속에 숨은 오타

- **문제**: 기존 수원시 보건소 사이트의 서비스 설명을 옮겨 오는 과정에서, 화면에 바로 보이지 않는 오타와 띄어쓰기 오류가 남아 있었음
- **원인**: 메뉴와 지원·자격 안내처럼 내용이 많은 부분을 아코디언으로 접어 두어, 항목을 하나씩 펼쳐 보지 않으면 오류를 발견할 수 없었음
- **해결**: 아코디언을 모두 펼쳐 가며 오타를 찾고, 해당 부분을 AI에게 수정하도록 요청함

## 6. AI 활용 방식

- **맡긴 일**: Figma 화면을 React 컴포넌트로 구현, 오타 부분 수정
- **핵심 프롬프트**: "이 프레임을 모바일 너비(360px~), 데스크톱(1440px~) 기준으로 구현해 줘", "오타와 띄어쓰기 부분 수정해 줘"

## 7. 회고

- **배운 점**
  - 배포 전에는 저장소가 Public으로 설정되어 있는지 반드시 확인해야 한다는 것을 배웠음
  - 아코디언처럼 접혀 있는 화면은 직접 펼쳐 보며 오타와 띄어쓰기를 검수해야 한다는 것을 알게 되었음
- **아쉬운 점**
  - 배포 전에 점검할 항목을 미리 정리해 두지 않아, 문제를 배포 후에야 발견하였음
  - 다음에는 저장소 공개 여부와 아코디언 전체 항목의 오타를 확인하는 체크리스트를 먼저 만들고 배포하려 함
