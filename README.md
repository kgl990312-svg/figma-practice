# 수원시 보건소 앱 개선 프로젝트

> 수원시 보건소 앱에 내 지역 버튼을 도입해 헛걸음을 줄인 개선안
>
> 보건 주요 서비스 카드를 재배치해, 필요한 서비스를 주소지 보건소에서만 신청할 수 있는지, 가까운 보건소에서도 신청할 수 있는지 한눈에 알 수 있도록 함
>
> 관할·통합·긴급 정보를 나눠 배치해 필요한 정보를 찾는 시간을 줄임

## 2. 프로젝트 정보

- **제작 기간**: 2026.11.06 ~ 2026.11.09 (4일)
- **담당 역할**: 개인 프로젝트 (기여도 100%)
- **담당 범위**: Figma 개선 디자인 → 바이브코딩 구현 → GitHub Pages 배포

## 3. 사용 기술

- **React, Vite**: 화면을 컴포넌트로 나눠 수정하기 쉽게 구현
- **GitHub Pages**: 무료 배포
- **Figma**: 개선 디자인
- **Claude**: 바이브코딩 (화면 구현)
- **준수 기준**: KRDS 2025.08, KWCAG 2.2

## 4. 주요 기능

- 기능 1: 서비스 카드를 세 영역(보건 주요 서비스 / 통합민원서비스 / 긴급원클릭서비스)으로 재배치해, 사용자가 원하는 서비스가 어떤 종류인지 쉽게 알고 알맞은 경로를 고를 수 있음
- 기능 2: 내 지역 버튼 도입 — 첫 화면의 안내문과 내 지역 버튼을 통해 사용자가 관할 보건사업을 헛걸음 없이 찾을 수 있음
- 기능 3: 긴급원클릭서비스 하단 고정 — 휴일지킴이, 자동심장충격기 찾기, 달빛어린이병원을 화면 하단에 고정해 휴일·야간에도 바로 찾을 수 있음
- 기능 4: 의료비지원 메뉴 11개 — 메뉴 버튼을 누르면 해당 지원사업 목록으로 바뀌어 자격·지원내용을 바로 확인할 수 있음
- 기능 5: 위치·교통 안내 — 구별 보건소 주소, 지도, 운영·점심시간, 대중교통·주차 정보를 한 화면에서 확인할 수 있음
- 기능 6: 지역별 공지사항 — 공통·팔달·권선·장안·영통 버튼으로 해당 지역의 최근 공지를 골라 볼 수 있음
- 기능 7: 모바일·데스크톱 반응형 레이아웃

## 5. 트러블슈팅

### 이슈 1: 배포 후 404 에러 화면이 나옴

- **문제**: 배포 후 주소 링크 공유 시 에러 화면이 나옴
- **원인**: GitHub 저장소가 Private으로 설정되어 있었음
- **해결**: 저장소를 Public으로 변경한 뒤 재배포하여 정상 접속 확인

### 이슈 2: 오타·띄어쓰기 확인과 수정에 시간이 오래 걸림

- **문제**: 화면 곳곳에 오타가 있어 수정에 가장 많은 시간이 걸림
- **원인**: 메뉴, 지원·자격 안내처럼 설명할 내용이 많은 아코디언 구조여서, 항목을 하나씩 펼쳐 봐야 숨은 오타를 확인할 수 있었음
- **해결**: 아코디언을 하나씩 펼쳐 가며 오타를 확인하고 해당 부분을 AI에게 수정 요청함

## 6. AI 활용 방식

- **맡긴 일**: Figma 화면을 React 컴포넌트로 구현, 오타 부분 수정
- **핵심 프롬프트**: "이 프레임을 모바일 너비(360px~), 데스크톱(1440px~) 기준으로 구현해 줘", "오타와 띄어쓰기 부분 수정해 줘"

## 7. 회고

- **배운 점**
  - 배포 전 저장소가 Public인지 꼭 확인하고 배포할 것
  - 접힌 화면(아코디언)은 직접 펼쳐서 오타와 띄어쓰기를 검수할 것
- **아쉬운 점**
  - 배포 전에 점검할 항목을 미리 정리해 두지 않아, 배포 후에야 문제를 발견하였음
  - 다음에는 저장소 공개 여부와 아코디언 전체 항목의 오타를 확인하는 체크리스트를 만들어 두고 배포할 것
